FUEGOff2 Creator Hub 17.1

Requisitos para publicación:
- Sube index.html y ads.txt a la raíz del sitio publicado.
- ads.txt debe quedar accesible en https://TU-DOMINIO/ads.txt
- La etiqueta meta de AdSense y el script ya están incluidos dentro de <head> en index.html.

Nota importante:
- El guardado local funciona sin servidor.
- La sincronización entre dispositivos requiere una API HTTPS real y autenticación segura.
- El servidor debe manejar datos de usuarios y almacenamiento persistente de forma compatible con el flujo del proyecto.

Este proyecto prepara la base para monetización con AdSense y para gestionar contenido, pero no inserta anuncios visibles por sí solo ni configura anuncios recompensados automáticamente. La aprobación final, la visibilidad y la disponibilidad de anuncios dependen de Google.
