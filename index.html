⚙️ Atributos HTML y buenas prácticas

Los atributos configuran un elemento; no son etiquetas. Estos son atributos globales y comunes que conviene conocer.

Globales

id identifica un elemento de forma única; class agrupa elementos; title aporta información; lang define idioma; dir define dirección; hidden oculta; tabindex controla foco; contenteditable permite edición; draggable habilita arrastre; data-* guarda datos propios; aria-* aporta información de accesibilidad.

Frecuentes por elemento

href destino de enlaces; src origen multimedia; alt alternativa textual; type tipo de control; name nombre enviado en formulario; value valor; placeholder pista; required obligatorio; disabled desactivado; for asocia etiqueta; target destino de enlace; rel relación del recurso; width/height dimensiones.

Accesibilidad: asocia cada campo con label, ofrece texto alternativo útil con alt, conserva el teclado, usa encabezados en orden y elige elementos semánticos antes que muchos div.

Elementos obsoletos: font, center, marquee, big, strike y frame se estudian solo por historia y compatibilidad; no se recomiendan en proyectos nuevos. Usa CSS y elementos modernos.

Requisitos del examen:
  1. HTML: título, descripción y al menos un botón o formulario.
  2. CSS: diseño legible, colores y adaptación para pantallas pequeñas.
  3. JavaScript: al menos una interacción que cambie el contenido.
  4. Prueba: ejecuta el proyecto y comprueba que la interacción funciona.
