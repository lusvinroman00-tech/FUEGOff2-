IMPORTANTE
1. Para que ambas páginas compartan localStorage deben publicarse bajo el mismo dominio y protocolo (mismo origen). Si se abren como archivos locales o en dominios distintos, no comparten datos.
2. La separación de interfaz no equivale a seguridad de servidor. El panel ADMIN todavía usa la autenticación local del HTML original; no se debe publicar como administración segura para datos sensibles sin backend con roles y reglas de autorización del lado servidor.
3. NOTICIAS guarda títulos, texto y URLs de medios/enlaces en el almacenamiento local del navegador. No sube archivos multimedia a la nube.
4. IA GLOBAL es un coordinador local basado en reglas. No conecta modelos externos ni realiza aprendizaje colectivo real. Para eso hace falta backend y proveedor de IA, con claves privadas guardadas en servidor.
5. Las funciones originales no se han reescrito en bloque. Se conservaron desde la base y se agregaron estas interfaces; no se ha certificado cada botón ni probado en un teléfono físico.
6. El HTML fuente declara versión 17.3 en varios textos internos aunque el archivo recibido se llama 17.5-1; se actualizó el título visible principal, pero pueden quedar etiquetas internas antiguas.

PRUEBA
Abre primero Creator Hub y luego ADMIN desde el mismo sitio publicado. Inicia sesión con la cuenta autorizada ya configurada en el navegador. No compartas contraseñas ni claves privadas.
